# ABSOLUTE UNIT · $RAM

An interactive one-screen coin site built around a framed vintage ram photograph and a planned SK hynix holder-payout pairing.

## Run locally

```bash
cd site
npm run dev
```

## Check and build

```bash
cd site
npm run check
npm run build
```

The official project X URL and contract address remain placeholders in `site/script.js` until supplied. The page also links directly to Elon Musk's referenced X post.
