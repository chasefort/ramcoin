# ABSOLUTE UNIT · $RAM

An interactive one-screen coin site styled like a rough black-and-white newspaper front page, built around the ABSOLUTE UNIT ram and a planned SK hynix holder-payout pairing.

## Run locally

```bash
cd site
npm run dev
```

## Check and build

```bash
cd site
npm run check
npm run build
```

The CA control copies the supplied contract address. The official project X URL remains a placeholder in `site/script.js` until supplied. The page also links to Elon Musk's referenced X post and the Know Your Meme history of Absolute Unit.
